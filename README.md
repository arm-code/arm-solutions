# arm-solutions

Proyecto web de **arm-solutions** — Ing. Alexis Romero Mendoza.

## Stack

- **React 19** + **Vite 7**
- **TypeScript 5.9** (strict mode)
- **Tailwind CSS v4** + tw-animate-css
- **shadcn/ui** (new-york, neutral)
- **React Router DOM v7**
- **pnpm**

## Inicio rápido

```bash
pnpm install
pnpm dev
```

## Deploy

Deploy automático vía GitHub Actions → FTP a Neubox al hacer push a `main`.
